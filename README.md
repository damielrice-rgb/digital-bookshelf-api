# Digital Bookshelf API

A simple REST API built with **Node.js, Express, and MongoDB** for managing a digital bookshelf.

## Features

* Connects to MongoDB Atlas
* Express REST API
* JSON request handling
* Environment variables for secure configuration
* CRUD operations for books

## Technologies

* Node.js
* Express
* MongoDB
* MongoDB Atlas
* dotenv

## Installation

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file and add your MongoDB connection string:

```env
MONGO_URI=your_mongodb_connection_string
PORT=3000
```

4. Start the server:

```bash
node server.js
```

## API

The API allows users to add, view, update, and delete books from the digital bookshelf.
